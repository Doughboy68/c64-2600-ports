ATARI 2600 → C64

Atari 2600 games ported to the Commodore 64. Build them from your own cartridge ROMs. Everything happens in this page; nothing is uploaded.

Drop a 2600 ROM and the game's profile here The ROM as .a26 (or the .zip it came in), and the profile as .json. Together, or one after the other; its README (.md) too, to read it here. Or click to choose files.

Supported games

Each needs one exact cartridge dump, recognised by its MD5. The number beside each game is the version of its C64 port. Click a game for details.

Profiles are plain data files: they hold a port's C64 code with every byte of the original game blanked out, so they're safe to share. Your ROM, checked by MD5, fills the gaps.

Download this page to use it offline: it's one file. Version 2026-10-04.
